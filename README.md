# ✈️ Yasin Aero Tour Website + Telegram Bot

Bu loyiha sayyohlik agentligi uchun oddiy website va Telegram bot integratsiyasidan iborat.

---

## 🚀 Funksiyalar

- 🌍 Turistik xizmatlar sayti
- 🛂 Aviabiletlar bo‘limi
- 🏨 Mehmonxonalar
- 📩 Buyurtma qoldirish formasi
- 📲 Telegram bot orqali mijoz xabarlari

---

## ⚙️ Ishlash tartibi

1. Foydalanuvchi saytda ism va telefonini kiritadi
2. “Yuborish” tugmasini bosadi
3. Ma’lumot Telegram botga yuboriladi

---

## 🔧 O‘rnatish

1. Repository’ni yuklab oling
2. `script.js` ichiga:
   - BOT TOKEN
   - CHAT ID

   ni kiriting

3. GitHub Pages yoki hostingga joylang

---

## 🤖 Telegram Bot sozlash

- BotFather orqali bot yarating
- Token oling
- Chat ID ni `getUpdates` orqali aniqlang
